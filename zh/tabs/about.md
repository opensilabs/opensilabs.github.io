## 关于 OpenSI-Labs

**OpenSI-Labs**（"Open Science Intelligence Labs"，开放科学智能实验室）是一个独立的开放出版计划，追踪人工智能的最前沿。

### 我们做什么

- **每天只给信号，不给噪音。** 每天精选一个最具爆炸性的进展，以权威资料为依据深入研究：学术期刊、顶级会议、实验室、科技媒体，以及 X 和 Reddit 上的实时讨论。
- **四种语言。** 每篇文章都以英语、中文、法语、日语发布。
- **天生开放。** 本站是由 Jekyll 生成的静态网站，托管于 GitHub Pages。文章是公开仓库中的 Markdown 文件；评论是通过 Giscus 实现的公开 GitHub Discussions——对话开放且永久可查。

### 覆盖方向

物理 AI 与机器人 · 世界模型 · 大语言模型与小语言模型 · 知识图谱与知识库 · 智能体 · 生物智能与仿生智能 · AI 芯片与基础设施。

### 联系我们

GitHub：[opensilabs](https://github.com/opensilabs)。如有指正、建议或选题请求，欢迎在任意文章下方留言——我们每一条都会看。
